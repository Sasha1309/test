# Учёт студентов

Консольное приложение на C#, которое позволяет вводить сведения о студентах, просматривать список, искать записи и сортировать их по среднему баллу.

## Возможности

- Создание студента с данными по умолчанию.
- Ввод имени, специальности, среднего балла и группы для каждого студента.
- Вывод всех введённых студентов.
- Поиск по имени, специальности, баллу или группе.
- Сортировка студентов по баллу по возрастанию или убыванию.
- При вводе балла принимаются и точка, и запятая в качестве десятичного разделителя.

## Требования

- Установленный .NET SDK.

## Запуск

Создайте консольный проект .NET, поместите код программы в `Program.cs`, затем выполните в папке проекта:

```bash
dotnet run
```

## Использование

1. Программа показывает студента по умолчанию.
2. Введите количество студентов.
3. Для каждого студента укажите имя, специальность, средний балл и группу.
4. Выберите поле для поиска и введите значение.
5. Выберите порядок сортировки по среднему баллу: `1` — по возрастанию, `2` — по убыванию.

При поиске укажите один из вариантов:

| Значение | Поле |
| --- | --- |
| `1` | Имя |
| `2` | Специальность |
| `3` | Средний балл |
| `4` | Группа |

## Пример вывода студента

```text
Анна Иванова | Информатика | Балл: 4,5 | Группа: ИС-21
```
